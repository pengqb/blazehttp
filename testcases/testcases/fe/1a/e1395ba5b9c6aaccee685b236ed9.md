## SQL 时间盲注攻击

**是的，这是一个 SQL 注入攻击**，具体为 **时间盲注（Time-Based Blind SQL Injection）**，并附带混淆注释干扰检测。

------

### 逐段解析

#### 完整 Payload 还原

sql

~~~sql
));WAITFOR DELAY '0:0:5'--
```

| 片段 | 含义 |
|---|---|
| `));` | 闭合前面的括号和语句 |
| `WAITFOR DELAY '0:0:5'` | SQL Server 专用：让数据库**等待5秒** |
| `--` | SQL 注释，截断后续语句 |

#### 混淆部分分析
```
-- entrieswednesdayrgbarectblockedaboutnarrowmutecapabilitiesplaceholder
```
这是一段**伪装成注释的垃圾字符串**，目的是：
- 填充内容干扰 WAF 关键词匹配
- 将 `WAITFOR` 拆分到下一行，绕过单行匹配规则
- 利用换行符逃逸检测

#### 攻击目标数据库
```
WAITFOR DELAY  →  Microsoft SQL Server 专用语法

其他数据库等效语句：
  MySQL    : SLEEP(5)
  Oracle   : dbms_pipe.receive_message('x',5)
  PostgreSQL: pg_sleep(5)
```

---

### 攻击原理
```
攻击者无法直接看到数据库返回内容
          ↓
通过注入 WAITFOR DELAY 让数据库延迟响应
          ↓
若响应时间 ≥ 5秒 → 注入成功，漏洞存在
若响应时间正常   → 注入失败或被过滤
          ↓
通过构造条件语句逐位提取数据：
IF (SUBSTRING(username,1,1)='a') WAITFOR DELAY '0:0:5'--
          ↓
每次延迟5秒 = 该字符为'a'，逐字符暴力枚举
~~~
